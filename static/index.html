RETRO / SFX

音源とプリセットを選び、ノブで調整して PLAY。作った音色は「パッチ保存」でJSONに保存でき、「読込」で再編集できます。変更内容はこのブラウザーにも自動保存されます。

ノブ：上下ドラッグ、フォーカス中の矢印キー、下の数値欄で操作。鍵盤は選んだ基準音で効果音全体を試聴します。LOOPは試聴専用です。

PITCHと8ステップは音程、AMPLITUDEはソフトウェア音量包絡です。A/Dは発音時間に収まるよう比例調整され、Rは発音時間の末尾に入ります。FMのAR/DR/SR/SL/RRは音源側の包絡をさらに設定します。TLは大きいほど小音量、MUL 0は0.5倍です。OPLLはM/Cの2オペレーター、AR/DRは0～15です。

PSGはYM2149モデル（AY-3-8910搭載機とは音量特性などが異なります）。OPN/OPNAはFMまたはSSGを編集できます。OPNAのADPCM・リズム、OPMのノイズ、複数チャンネルの同時編集は未対応です。実機のアナログ回路差までは再現しません。

VGMとREG JSON / C HEADERは試聴と同じレジスター列です。チャンネル0（PSGはA）用で、240 Hz更新・44,100 Hz時間基準。実機で使う場合はドライバー側でI/O待ち、共有レジスター、音楽との競合を扱ってください。WAVのDC除去と固定出力ゲインはVGMに含まれません。PANはOPNA/FMとOPMのみ有効です。

試聴音量は書き出しには影響しません。波形のCLIP表示が出たらLEVELまたは音色側の音量を下げてください。実機での動作は未検証です。
